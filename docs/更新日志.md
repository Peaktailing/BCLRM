# 试剂库管理系统 更新日志

## v0.86 (2026-07-04)
### 新增
- 四库分离数据库架构（main/archive_cold/attach_cold/operation_log），物理隔离不同用途数据
- 独立WAL日志目录配置（db_wal/main、archive、attach、logdb），避免WAL日志与数据库文件混放
- 操作审计日志表（operation_log），记录所有关键操作，纯追加写入
- 附件索引库（attach_cold.db），统一管理文件附件（MSDS、审批文件等）索引信息
- 前后端API接口规范文档（docs/API接口规范.md），定义35+ RESTful API端点
- 实验项目表（experiment_project）和实验试剂使用记录表（experiment_reagent_usage）
- 预定单表（reservation_order），支持学期预定、状态流转
- 采购单表（purchase_order），支持关联预定单、采购状态跟踪
- 学期统计功能，支持按学期维度筛选库存和领用数据

### 优化
- 数据库连接管理：MultiDatabaseManager 单例模式统一管理四个数据库连接，支持独立WAL目录
- 日志脱敏处理：SQL参数在写入日志前仅记录参数数量和类型，不记录实际值
- 冷库定期VACUUM碎片整理机制

### 安全
- 添加认证机制：所有页面需登录访问，API接口需Bearer Token认证
- 移除硬编码管理员列表，改为数据库person表管理
- 系统设置页数据库查看仅限管理员角色访问

### 文档
- 合并v3开发补充文档，新增数据库四库分离架构、实验项目管理、预定单管理、采购单管理、学期统计、API接口规范六个章节
- 更新文件结构目录，新增db_wal/、logs/、attachments/目录说明
