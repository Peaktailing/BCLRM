## v0.8.15 (2026-10-20)
### 只读代码审核后的集中修复（阻断/高危/主要中危）
- **运行时阻断**：修复试剂处置页 `ExpiryStatus` 未导入、系统设置页 `secrets` 未导入；两处页面不再 NameError
- **包结构**：移除 `services/business` 包级 eager import，解决循环依赖；`import services`、首次安装与数据导入脚本恢复可用
- **并发与事务**：事务临界区加锁 + 线程本地事务深度 + `BEGIN IMMEDIATE` + `busy_timeout`；借出/归还改为条件更新，避免跨会话/跨进程覆盖库存；采购入库改为逐项事务 + `bottle_number IS NULL` 条件回填，防重复入库；工单审批整段包裹单事务
- **管控审批**：统一 CAS/名称/别名判定（`controlled_list_service.match`），无 CAS 的管控试剂必须审批；采购单含管控化学品且未“已批准”时禁止提交，堵住绕过路径
- **认证安全**：历史 `salt:hash` 哈希识别并自动升级；空密码账户首次登录强制改密；新增用户改为一次性随机初始密码；登录锁定仍为会话级（后续可持久化）
- **归还/报废**：归还上限按“首次借出前总量”推导，支持严格模式多次部分归还；无领用记录禁止归还；报废/已报废统一退出可借池；归还量增加 NaN/Inf 校验
- **过期管理**：入库计算并写入 `expiry_date`；借出/智能调配前实时判定；新增“待确认”状态（缺生产日期/无法解析），看板与处置页提示补录；`sync_all` 修复“正常→已过期”时 check 未清零
- **单位模型**：`reagent_bottle`/`borrow_record`/`return_record`/`borrow_order_item`/`purchase_plan_item`/`purchase_order` 增加 `unit`（默认 g）；入库页支持 g/kg/mg/mL/L；采购与用量统计按“名称+CAS+单位”分组，g 与 mL 不再直接相加
- **采购与统计**：可用库存排除已借出；课程人数与用量统一来源学年/班级口径；`get_usage_by_course` 按班级取人数；`borrow_count` 仅统计生效工单；采购明细保存校验归属，封堵越权修改；预定转采购单加事务
- **权限**：新增 `enforce_role`；入库、化学品维护、采购生成/修改/提交/审批/入库/状态流转补服务层角色校验；入库页、化学品页增加管理员门禁；还入增加服务层归属校验
- **附件与审计**：MSDS 先更新数据库成功再删除旧文件，失败回收新文件；入库、报废/恢复、角色变更/删除用户补审计
- **配置**：CORS/XSRF 开启、错误详情关闭；数据库/日志/附件路径改为项目根目录绝对路径，避免分裂库；旧 `purchase_plan` 迁移改为 legacy 表保留，不再 DROP 数据
- **测试**：新增无 CAS 管控审批、管控采购单禁止未审批提交、重复部分归还防膨胀、无领用记录禁止归还、过期转换同步 check、g/mL 分行汇总等回归；附件索引测试隔离；全量 **186** 个测试通过

## v0.8.14 (2026-10-12)
### 工单服务与审批流（审批人边界 / 工单撤回 / 空瓶原子化等 10 项改进）
- **审批人边界（决策 1）**：正常提交的合格审批人 = 管理员（admin）账号——排除发起人本人、排除超管（`SUPER_ADMIN_APPROVER` 拒绝，提示走应急改派）；删除零星领用自动取第一个超管的逻辑，未指定审批人报 `NO_APPROVER`（请指定审批人）；自审批维持拒绝
- **应急改派通道**：新增 `reassign_approver`（仅 admin+ 可操作），候选 = admin + super_admin（页面超管选项标注「（应急）」），审计固定标记「应急重新指定审批人」——这是超管接管的唯一正常入口
- **工单撤回**：新增 `withdraw_order`（仅待审批；申请人本人或 admin+），工单/审批状态置「已撤回」（字符串字段零迁移）；审批页申请人本人可见「↩️ 撤回」
- **空瓶原子化（T2）**：`reagent_return` 增 `as_empty` 形参，空瓶迁移（「空瓶」+ 待报废）并入归还事务，删除后置独立 update——空瓶不再出现中间态；批量归还显式不触发
- **审批人手动指定（T6）**：领用页增审批人下拉（课程默认预选可改、零星必选、候选 = `list_approver_candidates` 管理员集合）；课程绑定审批人为超管（历史脏配置）不作为默认预选并提示重新指定
- **课程导入带入默认审批人（决策 2）**：课程导入表单增「默认审批人」（admin 候选），落库课程 `approver` 字段，领用时作为默认预选
- **审计操作人（T10）**：提交审批/发起工单审计记录实际操作人 `created_by`，代发起时 detail 注明「代 xx 提交」
- **领用人候选（T4）**：去除自由输入，候选 = 已建档人员 ∪ 历史领用人并集，分组标注「（已建档）/（历史记录）」，无匹配提示先建档
- **切课清清单（T7）**：课程/实验（或领用类型）切换侦测 → 警告 + 确认清空领用清单；提交前校验清单归属标记
- **搜索表防崩（T8）**：领用搜索结果表 `num_rows` 改 fixed，`_bottle_number` 缺失防御
- **登出清理（C2）**：新增可单测纯函数 `clear_business_session_state`，登出清空业务会话键（领用清单、需求明细等），保留登录态键
- **首页首屏（C3）**：用户手册默认折叠并移至页面底部，库存概览与快速入口保持首屏
- **处置页口径（D1）**：「恢复使用」复用 `recompute_borrowable` 统一可借性口径
- 测试：`test_approval` +8（审批人边界/撤回/应急改派/审计操作人）、`test_work_order` +2（空瓶迁移故障回滚/混合部分失败）并补空瓶四要素断言、`test_auth_session` 新增 3 例；全量 173 个测试通过
