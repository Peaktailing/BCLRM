# 试剂库管理系统 更新日志

## v0.8.12 (2026-10-12)
### 修复
- **课程采购单**：修复覆盖生成时 `manual_map` 未定义导致的 NameError（v0.8.11 遗留缺陷，「生成课程采购单」按钮必炸，3 个测试因此长期红）
- **MSDS 附件**：改为**真实存储**（`attachments/msds/` + 随机前缀防重名 + 附件索引库登记），编辑区新增**下载按钮**，替换附件时自动清理旧文件
- **历史数据清洗**：批量导入污染的 298 条 `msds='nan'` 规范为 NULL（幂等迁移）；旧系统 URL 格式附件（`/api/attachments/...`）明确提示"文件未迁移到本地，请重新上传"，不再显示错误文件名
- **测试语义对齐**：草稿（待采购）采购单不参与汇总为 v0.8.9 既定语义，测试补充提交环节与「草稿不纳入」断言

### 新增（架构加固）
- **服务端写权限守卫**（解决「不逐笔加代码」的统一方案）：
  - `utils/user_context.py`：ContextVar 登录上下文（登录/刷新注入，登出清除）
  - `utils/permission_guard.py`：**集中规则**——`person`/`controlled_list` 整表写保护、`approval_status` 审批字段保护；新增敏感项只需改这一个文件
  - `db/base_service.py`：create/update/delete 等**五个写方法统一拦截**，页面漏判也会被服务端兜底拒绝（`PermissionDeniedError` → `ServiceResult.fail`）
  - 无上下文（脚本/测试/初始化）放行，管理员及以上全放行；正常领用/归还/课程操作零影响
- **四库分离落地**：启动时自动初始化 `operation_log.db`（审计日志库，已切写并迁移 75 条历史）、`attach_cold.db`（附件索引库）、`archive_cold.db`（归档冷库占位）；`services/base/attachment_index_service.py` 独立附件索引服务
- **docs/架构演进规划.md**：FastAPI 后端层、登录失败锁定持久化、权限守卫中台化、归档数据搬运的实施规划与触发条件

### 其他（CodeBuddy 协作改动，一并合入）
- 批量指定管理人：`manager_service.bulk_assign_manager`（逐瓶复用 transfer 校验 + 变更历史）+ 试剂处置页入口（范围：仅未指定管理人 / 按关键字过滤）
- 采购单入库支持生产日期与存储位置参数；采购量为 0 的明细视为已处置，不再永久阻塞采购单完成
- 数据导入脚本新增 `--manager` 参数（导入时指定保管权归属，校验人员存在）

### 测试
- **144 个测试全部通过**（131 原有 + 6 权限守卫专项 + 7 附件存储专项）
- 页面冒烟：登录 / 首页 / 实时库存 / 化学品信息管理 / 采购管理 / 领用归还 / 数据看板 全部正常，无 traceback

## v0.8.11 (2026-09-30)
### 修复（业务逻辑审计，7 高危 / 11 中危 / 9 低危）
- **统计口径**：用量统计排除「待审批 / 已驳回」工单，修正学期用量、看板与**采购人均用量测算**的长期偏高
- **采购**：采购量填 0 不再回退需求量（消除凭空造库存）；取消采购单时清空审批痕迹（堵住危化品审批绕过）；覆盖生成保留人工修改；汇总按**采购量**计算最终采购量并新增「总采购量」列；同名不同 CAS 分别汇总并告警；批量入库新增生产日期（必填）与试剂类型回填
- **工单**：领用扣库存与工单落库合并为同一事务（消除「已扣库存但无工单、瓶永久卡死」）；审批回写精确到本工单流水（不再污染该瓶历史记录）；空瓶改为显式勾选确认（归还比例 0% 不再隐式判空瓶）；非管理员工单鉴权不再因 user_name 为空而失效；负数归还量给出明确提示
- **试剂瓶状态**：可借状态以 `borrowable_flag` 为事实源、`borrowable_check` 在服务层统一派生；过期瓶同步退出可借集合，恢复正常后可回归；确认报废同步置不可借，恢复时若仍过期则不放回可借池
- **管控与安全**：无 CAS 的历史试剂按名称兜底匹配管控名录（避免危化品绕过审批）
- **管理权/调配**：借出中的瓶禁止流转管理权；新管理人必须是真实人员；调配单预占瓶（同一瓶不再被多个需求重复分配）；借出前复校验可借状态；管理人存量口径与分组口径统一；撤销需求需本人或管理员
- **统计**：看板分类互斥且穷尽（分类之和 = 总数），报废瓶余量不计入可用总量；采购存量排除报废与已过期瓶
- **数据修复**：2 个「已借出」但无借用记录的孤儿瓶已修正为「耗尽」
- 详见 [BUG 修复报告](BUG修复报告.md)

## v0.8.10 (2026-09-30)
### 修复（代码自审 + 遗留问题）
- 需求调配：需求人限定为**管理员及以上**（服务端校验 + 页面下拉限制）
- 需求调配：处理调配单增加**操作人校验**，仅该单受理管理人或超管可借出 / 退回
- 需求调配：借出**部分失败**时不再整单标记「已借出」，保持「待处理」可重试，需求状态不再误判为已完成；重复处理时已流转明细自动跳过（幂等）

- 试剂处置：管理权流转成功后**清空勾选**，避免残留失效选择被再次提交
- 采购：**审批中的采购单锁定**明细修改（需审批人驳回后再改）
- 采购：预定单**批准时可补填需求学年**；未填学年的已批准预定单在汇总时**明确提示**（不再静默忽略）
- 采购：空明细采购单不再被判定为「已入库」
- 数据库：管理人回填迁移**仅在新增列时执行一次**，启动不再覆盖人工清空的管理人
