# 试剂库管理系统 更新日志

## v0.8.10 (2026-09-30)
### 修复（代码自审 + 遗留问题）
- 需求调配：需求人限定为**管理员及以上**（服务端校验 + 页面下拉限制）
- 需求调配：处理调配单增加**操作人校验**，仅该单受理管理人或超管可借出 / 退回
- 需求调配：借出**部分失败**时不再整单标记「已借出」，保持「待处理」可重试，需求状态不再误判为已完成；重复处理时已流转明细自动跳过（幂等）
- 需求调配：同一需求内**不再重复分配同一瓶**；**同一管理人 + 同一试剂合并为一张调配单**
- 需求调配：新增**「撤销需求」**（无已借出调配单时可用），解决提交后无可借试剂导致的卡单
- 试剂处置：管理权流转成功后**清空勾选**，避免残留失效选择被再次提交
- 采购：**审批中的采购单锁定**明细修改（需审批人驳回后再改）
- 采购：预定单**批准时可补填需求学年**；未填学年的已批准预定单在汇总时**明确提示**（不再静默忽略）
- 采购：空明细采购单不再被判定为「已入库」
- 数据库：管理人回填迁移**仅在新增列时执行一次**，启动不再覆盖人工清空的管理人

## v0.8.9 (2026-09-29)
### 新增
- 试剂管理人（保管权）体系：入库指定管理人（默认当前登录管理员），无管理人自动归属超级管理员
- 「试剂处置」页新增「🔁 管理权流转」：多选 / 批量把试剂管理权流转给同事，逐瓶记录变更历史
- 领用归还页新增「🔀 需求调配」：提交需求 → 按管理人拆分调配单（智能分配：本人 → 本教研室 → 全院），管理员借出（管理权流转到需求人）/ 退回
- 首页挂载「📖 用户使用手册」（渲染 docs/用户使用手册.md）

### 变更
- 「🗑️ 待报废与过期预警」页面更名为「🧰 试剂处置」，管理权流转从「实时库存」页移入
- 采购流程补全：课程采购单新增「🚀 提交采购单」（纳入汇总与跟踪）；汇总采购单纳入已批准预定单；采购单跟踪纳入课程采购单（已提交→已下单→已到货→已入库）；明细「已改」标记仅在真正修改时勾选且保存后立即刷新；提交后的采购单从「采购单管理」消失且锁定不可再改（含明细、审批、覆盖生成三重防护）
- 采购单跟踪新增「❌ 取消」：到货前可取消，退回草稿「待采购」重新编辑
- 试剂入库新增「📦 按采购单入库」：对已到货的采购单按明细批量入库，回填瓶号防重复，全部完成自动变「已入库」；历史试剂缺 CAS / 未建化学品档案也可入库
- 化学品重复校验同时匹配「化学品名称」与「通用显示名称」，重复提示明确指出命中的条目，编辑下拉显示「名称（通用显示名称）」
- README 重写为实际功能与部署说明

## v0.9.0 (2026-09-24)
### 新增
- 工单制领用归还：零星/课程两种领用工单，多瓶合并一张工单；归还按工单逐瓶「勾选 + 百分比滑块」估算，勾选即结清（差额计为使用量）
- 归还比例 0% 记为「空瓶」，自动移入待报废清单；新建「🗑️ 待报废与过期预警」页面（全选、确认报废/恢复使用，管理员及以上）
- 默认实验方案与人均用量：课程管理页维护方案文本与人均用量，支持「按最近一次工单导入」折算；领用时按人数自动生成清单，支持按人数重算与单瓶修改
- 课程管理：分组表导入实验项目跨学年去重；超管手动新增课程/实验项目；删除实验项目/课程（仅超管）；维护操作限管理员及以上
- 学期用量：新增「课程 → 实验 → 试剂」维度统计，同一实验名合并不分班级，人均 = 平均用量 ÷ 班级平均人数
- 实验进度状态：课程领用后标记「已借出试剂」，工单全部归还后标记「已还入试剂」
- 数据看板进入时自动刷新过期状态

### 修复
- 化学品重复提示不明确：重复判断同时命中「名称/通用显示名称」时，现在会明确指出命中的记录（名称、显示名、CAS）并引导到编辑区
- 化学品编辑下拉只按名称列出，导致「氯化氢水溶液（盐酸）」这类记录难以找到：下拉改为「名称（通用显示名称）」格式，并直接使用选中对象更新，避免按名称二次查询错位
- 课程管理页导入时未传入实验项目导致实验从未被导入的缺陷
- 工单部分归还状态判定兼容严格模式与空瓶结清场景

### 安全
- SQL LIMIT 参数强制整数转换；数据库文件与临时导出目录移出 git 跟踪
