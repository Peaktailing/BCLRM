# 试剂库管理系统 - 用户使用手册
**版本：v0.8.16 | 日期：2026-10-26**

> 导航随角色变化：教师看到 14 个入口，管理员多「待办队列」「调配台」两页，
> 系统设置仅超级管理员可见。新增页面见 3.13–3.16。

---

## 一、系统概述

本系统是一个基于 Streamlit 的试剂库存管理系统，实现试剂的入库、领用（工单制）、归还、课程实验管理、学期用量统计与报废预警的全流程管理。系统支持管控化学品自动标记与审批，方便实验室进行试剂安全管理。

## 三、功能使用说明

### 3.1 实时库存

**功能**：查看当前所有试剂的库存状态

**操作说明**：
1. 进入「实时库存」页面
2. 页面显示试剂瓶总数、可借数量、已借出、耗尽等统计信息
3. 支持按名称、CAS号、编号搜索，按状态筛选（全部、可借、已借出、耗尽、空瓶）

---

### 3.2 试剂入库

**功能**：将新试剂录入系统

**操作说明**：
1. 进入「试剂入库」页面
2. 填写必填字段（带*号）：条码*、CAS号*、试剂名称*、剩余量(g)*、规格(g)*
3. 可选字段：纯度、采购单价、供应商、生产日期、存储位置、有效期等
4. 点击「确认入库」提交

**注意事项**：
- 条码必须唯一
- 如果CAS号不在化学品信息表中，会提示建议先到「化学品信息管理」添加

**📦 按采购单入库（已到货）**：
- 选择「已到货」的课程采购单，按明细**批量生成试剂瓶**（数量取采购量，管理人默认当前登录管理员）
- 明细入库后自动回填瓶号，**防止重复入库**；全部入库完成，采购单自动变为「已入库」
- 历史试剂若未建化学品档案 / 缺 CAS，也可入库（能查到 CAS 会自动带上）

---

### 3.3 领用归还（工单制）

#### 3.3.1 领用（生成工单）

领用分两种类型，多瓶试剂会合并为**同一张工单**的多条明细：

**零星领用**：
1. 在搜索表格中选择试剂瓶加入领用清单（领用量默认为整瓶剩余量，可修改）
2. 填写领用人，点击提交

**课程领用（推荐流程）**：
1. 选择课程与实验项目，页面会显示该实验的当前进度（未领用 / 已借出试剂 / 已还入试剂）
2. 若已配置**默认实验方案**：填写「班级人数」→ 点「📋 加载默认实验方案」，清单总量 = 人均用量 × 人数
3. 若未配置默认方案但有**历史领用工单**：可点「📋 从历史工单生成默认领用清单」
4. 清单支持两种调整方式：
   - **按人数改**：填人数 → 点「🔁 按人数重算清单用量」
   - **单瓶改**：直接修改某行的「领用量」
5. 提交后生成领用工单，该实验自动标记为「已借出试剂」

**注意事项**：
- 只能领用「可借」状态的试剂
- 每行领用量必须大于 0
- 管控试剂需要**两名管理员**先后签字（审批 + 复核）

#### 3.3.2 归还（按工单归还）

1. 进入「领用归还」页面，选择「归还」标签，选择一张领用工单
2. 页面显示：工单共 N 瓶，待归还 M 瓶，已归还 K 瓶
3. 每瓶一行：**勾选「还入」+ 调整「归还比例」滑块（0%~100%，默认100%）**，右侧实时显示本次还回量
4. 点击「提交归还」

**归还规则（重要）**：
- **勾选并提交后，该瓶即结清**（不再出现在待还列表），未还回的差额计入实际使用量
- 例：借 4 瓶只勾 1 瓶提交 → 工单变「部分归还」，剩 3 瓶继续待还
- **归还比例 = 0% 表示空瓶**：该瓶记为「空瓶」并自动移入「试剂处置」的待报废清单
- 工单所有明细结清后，工单变「已归还」，对应实验自动标记为「已还入试剂」

#### 3.3.3 需求调配（🔀 标签页）

> 这一节是「领用归还」页里的旧通道：按管理人拆单，由受理人决定借出/退回。
> 管理员之间的横向调拨现在优先用独立的「🔀 调配台」（见 3.16）——由缺料人
> 发起、出料人本人点头。两条通道都还在，新流程见 3.16。

用于**管理员之间流转试剂**：我有需求 → 提交需求 → 系统按管理人拆出调配单 → 管理员决定借出 / 退回。

**发起需求**：
1. 选择「需求人」（**仅管理员及以上**可被选为需求人，需求调配不面向普通用户）
2. 选择试剂 + 填需求量 → 「➕ 加入需求清单」→ 可继续添加（同一试剂可加多条）
3. 点「提交需求」→ 系统智能分配并生成调配单

**智能分配规则**：优先 **本人 → 本教研室（部门相同）→ 全院**；组内按效期先到期先用；同一需求内**同一瓶不会重复分配**；**同一管理人 + 同一试剂合并为一张调配单**。

**智能计算（供受理人决策参考）**：显示本年度需求量 / 你的可借存量 / 全院可借存量，并提示「✅ 足够 / ⚠️ 可能不足」——**仅供参考，不阻断决策**。

**受理人处理**（仅该单受理管理人或超管可操作）：
- **✅ 借出**：把试剂管理权流转到需求人名下，并写入一条管理人变更记录
- **❌ 退回**：驳回该调配单
- 若部分瓶失败，单据保持「待处理」可重试（已成功的瓶不会重复流转）

**我的需求进度**：查看自己提交的需求及其调配单状态；在**没有任何调配单借出**时可「🚫 撤销该需求」，相关未处理调配单会一并退回。

### 3.5 数据看板

**功能**：统计报表和可视化图表

- 进入页面时会**自动刷新一次过期状态**并提示本次更新了几瓶
- 库存概览、领用/归还统计、领用排行、试剂分布、存储位置分布等

---

### 3.6 学期用量

**功能**：按学期统计试剂用量与人均

- 汇总指标：总用量、领用人数、试剂种类、领用/归还次数
- **「课程 → 实验 → 试剂」维度明细**（核心口径）：
  - 同一课程下「实验名称 + 试剂名称」相同即合并为一行，**不分班级**
  - 平均用量 = 合计用量 ÷ 班级数
  - **人均用量 = 平均用量 ÷ 班级平均人数**
- 支持按课程筛选，附用量条形图

---

### 3.7 课程管理

三个标签页：**📥 导入课程**、**➕ 新增课程/实验**、**📋 课程列表**

#### 导入课程（管理员及以上）
1. 上传实验分组表（Excel），填写学年、学期等信息
2. 系统解析出课程与实验项目；实验项目按「课程名 + 实验名」**跨学年去重**——往年已导入的只更新序号/学年，不会重复插入
3. 点「确认导入」，结果会显示新增 / 更新 / 去重跳过 / 失败数量

#### 新增课程 / 实验项目（仅超级管理员）
- 手动录入课程（学年 + 学期 + 课程名 + 班级唯一）
- 从已有课程下添加实验项目（序号自动预填，同课程下实验名不可重复）

#### 默认实验方案与用量（管理员及以上）
在「课程列表」中选择课程 → 选择实验：
- **实验方案文本**：实验目的、步骤、注意事项
- **默认用量表**：试剂名称 / **人均用量** / 单位 / 来源，可增删改
- **📥 按最近一次工单导入默认用量**：按「折算人数」把最近一次工单的整班量折算为人均
- **按人数预览**本次领用总量
- 默认方案按「课程名 + 实验名」存储，**跨学年复用**

#### 删除（仅超级管理员）
- 删除实验项目：只删实验，**课程与其他实验保留**
- 删除课程：删除整门课程

#### 权限一览

| 操作 | 角色要求 |
|---|---|
| 查看 | 所有登录用户（只读） |
| 导入课程 / 维护默认方案 | 管理员及以上 |
| 新增课程、新增实验项目 | 仅超级管理员 |
| 删除实验项目 / 删除课程 | 仅超级管理员 |

### 3.8 试剂处置

**Tab 1 · 待报废清单**：
- 归还时比例 0% 的空瓶自动进入本清单
- 支持**全选 / 取消全选**，勾选后「✅ 确认报废」（标记已报废）或「↩️ 恢复使用」（清空报废标记并重算可借状态）
- 确认报废 / 恢复使用需**管理员及以上**权限

**Tab 2 · 过期预警**：
- 合并展示「已过期」与「即将过期」试剂，含是否待报废、可借状态

**Tab 3 · 管理权流转**：
- 把试剂的管理权（保管权）流转给同事；支持**多选 / 批量**（可搜索过滤、全选）
- 选择试剂 → 勾选 → 选「新管理人」→「🔁 确认流转」，每瓶都会记录一条管理人变更历史
- 注意：**领用 / 归还不会改变管理人**，只有此处、需求调配与「调配台」会变更管理人
- 需**管理员及以上**权限

---

### 3.9 化学品信息管理

#### 添加化学品
1. 选择试剂类型（可多选，有效期自动取所选类型中最短默认值）、存储要求
2. 填写化学品名称、CAS号等信息；MSDS 可上传附件
3. 提交

**重复提示说明**：系统判断重复时会**同时匹配「化学品名称」和「通用显示名称」**。例如库中已有「氯化氢水溶液（通用显示名称：盐酸）」时，再添加「盐酸」会提示已存在，并**明确指出命中的是哪条记录**（含名称、显示名、CAS）。此时请到下方「编辑化学品」中修改该条目，而不是重复添加。

#### 编辑化学品
- 下拉格式为 **「化学品名称（通用显示名称）」**，例如 `氯化氢水溶液（盐酸）`，方便按常用名找到条目
- 修改后点「更新化学品」；CAS 变化会自动重新匹配管控类型

#### 试剂类型有效期配置
- 为每种试剂类型设置默认未启封/启封有效期，录入化学品时自动填充

### 3.11 采购管理

**Tab 1 · 生成课程采购单**：
选来源学年 + 课程 + 预计人数 → 预览人均用量与需求 → 生成/覆盖（状态为草稿「待采购」）。

**Tab 2 · 采购单管理**：
- **「🚀 提交采购单」**：把草稿提交进汇总采购单与采购单跟踪（含管控化学品的单需先审批通过）
- **「📨 提交审批」**：含管控化学品时指定审批人走审批流
- 明细可修改需求量 / 采购量 / 供应商 / 备注；保存后**真正改过的行会自动勾上「已改」**
- **审批中的采购单锁定**：`待审批` 状态下不能再修改明细，需审批人驳回后再改

**Tab 3 · 汇总采购单（超管）**：
汇总范围 = **已提交**的课程采购单 + **已批准**的预定单（按需求学年归集），按试剂合并需求并统一扣减一次库存，可导出 Excel。

**Tab 4 · 预定单**：
库存不足时提交预定 → 管理员批准（**批准时可补填「需求学年」**）→ 批准后既可「转为采购单」，也会按需求学年自动进入对应学年的汇总采购单。
- 已批准但**未填需求学年**的预定单不会被归集到任何学年，汇总时会明确提示数量，请及时补填。

**Tab 5 · 采购单跟踪**：
课程采购单（已提交 → 已下单 → 已到货 → 已入库）与预定转来的采购单（待下单 → 已下单 → 已到货）统一跟踪。
- **到货前可「❌ 取消」**：退回草稿「待采购」，可重新编辑后再提交
- 到货后到「试剂入库 → 📦 按采购单入库」批量入库，入库完成自动变「已入库」

### 3.13 配方与需求

五个标签页：**📚 配方库 / ✍️ 配方编制 / 🧮 需求试算 / 📄 需求量与单据 / 🔀 申领流转**。

**发起需求（教师）**：
1. 在「配方编制」录入或修改配方（物质、角色、单位用量）。
2. 在「需求试算」选择配方、填写人数/批次数，查看每项的可用量、缺口与采购建议。
3. 点「生成需求单」；到「需求量与单据」看最近单据、状态和退回原因。
4. 单指定给某个人却一直没人批：在「我的在办需求单」里「放给组」「放给全院」或「改派」。
   单的内容不变，只是换收件人。

**受理与兑付（管理员）**：
1. 在「待办队列」（3.15）接单，单进入自己名下。
2. 到本页「申领流转」看保管账与受理结论；点「受理这张申请」，再逐项勾选转借出单。
3. 含管制化学品的单，需指定**另一名管理员**复核；复核通过后才能兑付发料。
4. 手上不够不是退单理由：用「调配台」（3.16）向别处调。

**注意**：「退回修改」是单本身有问题（退给申请人改）；「放给组/全院」只是换收件人，
单还在办。两者不要混。

### 3.14 手机取证

瓶身二维码指向短地址 `/m?bottle=...`，手机扫码后：

1. 若手机还没登录，会先显示登录页；登录成功后仍停在这一瓶，不会跳回首页。
2. 页面显示这一瓶的名称、剩余量、保管人、位置与效期。
3. 找到这一瓶当前的那张单，在「借出照片」「归还照片」处拍照或选图上传。
4. 必填项会在标签上标注；已上传的照片可展开查看、下载原图。照片墙在手机上是
   两列，点「看原图」可核对批号。
5. 扫码识别不了时，可以直接输入瓶号。

上传成功或部分失败会在页面顶部提示；失败会列出具体哪张、为什么没存上。
「待审批」的单也可以先拍，但页面会说明这只是补充材料，正式发料仍要在电脑端审批。

手机端地址、照片是否必填、大小与格式限制，由超管在「系统设置 → 现场取证」配置。
地址可以只写 `192.168.1.10:8601`，保存时会自动补 `http://`；修改地址后，已经
打印的旧标签需要重打。照片只收 JPG / PNG / WebP，iPhone 请直接用相机拍或先在
相册里转成 JPG，不要选 HEIC 原图。瓶身标签在「实时库存」勾选瓶子后生成。

如果系统是通过 SSH 端口转发访问的（浏览器地址是 `http://localhost:8501`），
「手机访问地址」可以留空。打印标签时在「码里放什么」选**跟随当前访问地址**，
二维码会按你此刻的入口生成；页内扫码也总是跳回当前入口，不用改配置。注意这种
标签只对**同样做了端口转发的手机**有效——同事手机没开隧道时打不开，换端口后
需要重打。照片上传本身只走当前连接，不受地址配置影响。

手机端只做现场取证；审批、改单、查账请回电脑端完成。

### 3.15 待办队列（管理员）

把零星/课程领用工单与配方需求单排成一队，按提交时间升序。

- 顶部四个数字：**我名下 / 我的组 / 全院池 / 合计**。
- 归属三级：指定给某人（只有他看得见）→ 我的组（组内任一管理员可接可办）→
  全院池（全院管理员可接可办）。
- 选中一张单后可以：
  - **接单**：把单认领到自己名下；
  - **退回修改**：单本身有问题，退给申请人改，原因可选；
  - **改派**：换一个人或一个组办，单仍在办。
- 如果有调拨单等你点头，页面上方会提示去「调配台」。
- 教师看不到本页；教师的申请进度在「配方与需求 → 需求量与单据」和「领用归还」查看。

### 3.16 调配台（管理员）

管理员之间的横向通道。**调的是保管权，不是实物**：瓶子不动、库存总量不变，
变更会写进管理人变更记录。

| 标签 | 用途 |
|---|---|
| 待我点头 | 别人要从你名下调料：逐行勾选同意/不同意，可部分同意；不同意必须写理由 |
| 我的缺口 | 你名下还没发出去的量：点「算一算该找谁调」，选建议后发起 |
| 我发起的 | 看进度、撤回还没被点头的单、标记实物已取走 |
| 全院在办 | 只读，看全院正在办的调拨 |

**谁能点头**：只有出料人本人。超级管理员可以代签，但必须写理由并留痕。
同意那一刻就改保管权；实物什么时候搬是线下的事，用「标记已取走」记一笔，不阻断流程。

## 四、权限说明

### 4.1 权限等级

| 权限等级 | 权限说明 |
|----------|----------|
| 普通用户（user） | 领用、归还、查询 |
| 教师（teacher） | 同普通用户；可发起需求；**不参与审批** |
| 管理员（admin） | 入库、课程导入、默认方案维护、报废确认、审批与复核、待办队列、调配台 |
| 超级管理员（super_admin） | 全部权限；另有系统设置、课程/实验/化学品删除、调拨代签 |

### 4.2 权限分配

由超级管理员在「系统设置」中管理用户与角色。组与成员的维护目前没有页面入口，
由系统管理员在后台处理。

## 五、注意事项

1. **工单制领还**：领用和归还都以「工单」为单位，归还时按瓶勾选结清
2. **空瓶处理**：归还比例 0% = 空瓶，会进入待报废清单等待处置
3. **管控试剂**：管控化学品数据为只读；工单或需求单含管控试剂时，需**两名管理员**
   先后签字（审批 + 复核），复核通过后才发料
4. **条码唯一**：每个试剂瓶的条码必须唯一
5. **默认方案跨学年**：默认实验方案按「课程名 + 实验名」存储，新学年无需重新配置
6. **导入去重**：分组表可整表重复导入，系统按「课程名 + 实验名」自动去重
7. **组池**：一个管理员可以属于多个组（教研室 / 科研组）；组池的单组内任一管理员
   都能接，指定给个人的单只有本人能接
8. **调配与采购的区别**：调配只换「算谁名下」，库存总量不变；采购才增加总量

## 六、常见问题

### 6.1 添加化学品提示「已存在」但列表里找不到？
系统会同时匹配「化学品名称」和「通用显示名称」。例如要添加「盐酸」，若库中已有「氯化氢水溶液（通用显示名称：盐酸）」，会提示已存在并指出该条目。请在「编辑化学品」下拉中查找（下拉会显示「名称（通用显示名称）」），找到后直接修改该条目。

### 6.2 归还时某瓶想标记为用完了（空瓶）？
把该瓶的归还比例滑块调到 0%，勾选后提交，该瓶即记为空瓶并进入「试剂处置」的待报废清单。

### 6.3 新学年实验方案要重新配吗？
不用。默认实验方案按「课程名 + 实验名」跨学年复用；导入新学年分组表时实验项目也会自动去重。

### 6.4 领用/归还后实验进度没变？
课程领用工单创建后标记「已借出试剂」；工单**全部明细**归还后才标记「已还入试剂」。

### 6.5 页面数据不显示
检查数据库连接，或联系系统管理员。

### 6.6 待办队列里看不到某张单？
先确认它是否指定给了别人或别的组；指定给个人的单只有本人看得见。已经办结的单
不会出现在队列里。超级管理员可以在「全院池」确认单还在不在。

### 6.7 调配台里为什么没有「同意」按钮？
只有出料人本人能点头；指定给别人的单不会出现在你的「待我点头」里。超级管理员
可以代签，但必须写理由。
